# Strategy Generator

## Setup Instructions

This project uses Conda to manage dependencies. To set up the project locally, follow the instructions below to create a virtual environment with the correct Python version and libraries.

1. **Create a new conda environment:**
   This command creates a new local environment in the `./env` directory using Python 3.11 and installs the required data science libraries (`pandas`, `scikit-learn`, and `scipy`).

   ```bash
   conda create -p ./env python=3.11 pandas scikit-learn scipy
   ```

2. **Activate the environment:**
   Once the environment is created, activate it to start working on the project.

   ```bash
   conda activate ./env
   ```
